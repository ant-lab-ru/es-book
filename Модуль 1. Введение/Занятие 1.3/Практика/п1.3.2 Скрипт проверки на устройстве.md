**Результат** — в проекте `131-hello-usb` появился скрипт на языке Python. Он находит вашу плату среди USB-устройств компьютера, слушает её десять секунд и записывает принятое в файл. Этот файл — свидетельство того, что прошивка работает на реальной плате.

## Задание

### Что должно получиться

- [ ] Установлена библиотека `pyserial`
- [ ] В папке `131-hello-usb` создан скрипт `check-1-3-2.py`
- [ ] Скрипт находит плату по коду USB-устройства, а не по имени порта
- [ ] Рядом с `main.c` лежит файл `device-1-3-2.log` с принятыми строками

### Как проверить

1. **Скрипт отчитывается в терминале.** Он печатает имя порта, на котором нашёл плату, и число принятых строк — их должно быть около десяти.
2. **Лог остался на диске.** В начале файла — номер задания, код USB-устройства, серийный номер платы и имя порта. Дальше строки `Hello, world!` с метками времени, в конце итог.
3. **Автоматическая проверка курса принимает задание.** Она читает скрипт: плата ищется по коду производителя и устройства, у порта задано предельное время ожидания. И читает лог: сверяет код устройства и серийный номер с платой Raspberry Pi Pico, считает строки и измеряет интервал между ними. Прошивку она здесь не собирает — это сделано в прошлом задании.

## Ход работы

>[!info] Зачем прибору собеседник на компьютере
>Терминал показал, что прошивка работает, но окно закроется и следа не останется. А проверке курса, которая запускается на сервере GitHub, вашей платы не видно вовсе: там нет ни кабеля, ни USB — только ваш репозиторий.
>
>Значит, свидетельство работы нужно сохранить на диск и отправить в репозиторий. Этим займётся скрипт на языке Python — программа на стороне компьютера, которая слушает прибор. В модуле 3 вы будете собрать похожим скриптом измерения с датчиков, а в модуле 4 — рисовать по ним графики.

### 1. Установить библиотеку для работы с портом

Сам язык Python у вас уже стоит: он нужен сборке Pico SDK, вы поставили его в [[п1.1.1 Установка инструментов#^intro|п1.1.1]]. Не хватает библиотеки, которая умеет открывать последовательный порт:

``` bash
pip install pyserial
```

>[!bug] Команда pip не найдена
>В macOS и Linux интерпретатор и его менеджер пакетов чаще вызываются как `python3` и `pip3`. Если `pip` не находится, попробуйте `pip3 install pyserial`. Подробности — в карточке [[Python#Установка\|Python]].

### 2. Создать скрипт проверки

Создайте в папке `131-hello-usb` файл `check-1-3-2.py` — рядом с `main.c`, потому что относится он к этому проекту. Наберите в нём программу целиком.

Плата ищется по коду производителя и устройства, а не по имени порта: имя каждый раз своё и в разных системах выглядит по-разному. `0x2E8A` — код Raspberry Pi, `0x000A` — код платы с запущенной прошивкой. Эти числа и серийный номер скрипт запишет в лог, и по ним проверка увидит, что на другом конце провода была именно Pico.

>[!success] Должно получиться так
> ```python
> # Проверка задания п1.3.2 на устройстве: слушает COM-порт платы
> # и записывает всё принятое в файл device-1-3-2.log.
>
> import time
> from datetime import datetime
>
> import serial
> from serial.tools import list_ports
>
> VENDOR_ID = 0x2E8A
> PRODUCT_ID = 0x000A
>
> TASK = "1.3.2"
> PROJECT = "131-hello-usb"
> LOG_NAME = "device-1-3-2.log"
> DURATION_S = 10
>
>
> def find_board():
>     for port in list_ports.comports():
>         if port.vid == VENDOR_ID and port.pid == PRODUCT_ID:
>             return port
>     return None
>
>
> def listen(board):
>     lines = []
>     with serial.Serial(board.device, timeout=1) as port:
>         time.sleep(0.2)
>         port.reset_input_buffer()
>         started = time.monotonic()
>         while time.monotonic() - started < DURATION_S:
>             line = port.readline().decode("ascii", "replace").strip()
>             if line:
>                 lines.append((time.monotonic() - started, line))
>     return lines
>
>
> def write_log(board, lines):
>     with open(LOG_NAME, "w", encoding="utf-8") as log:
>         log.write("задание: " + TASK + "\n")
>         log.write("проект: " + PROJECT + "\n")
>         log.write("устройство: %04x:%04x\n" % (board.vid, board.pid))
>         log.write("серийный номер: " + str(board.serial_number) + "\n")
>         log.write("порт: " + board.device + "\n")
>         log.write("начало: " + datetime.now().isoformat(timespec="seconds") + "\n")
>         for moment, line in lines:
>             log.write("%8.3f <-- %s\n" % (moment, line))
>         log.write("итог: принято строк %d за %.1f с\n" % (len(lines), DURATION_S))
>
>
> board = find_board()
>
> if board is None:
>     print("Плата не найдена. Проверьте кабель и запишите на плату прошивку задания.", end="\r\n")
> else:
>     print("Плата на порту " + board.device + ", слушаю %d секунд" % DURATION_S, end="\r\n")
>     lines = listen(board)
>     write_log(board, lines)
>     print("Принято строк: %d, лог записан в %s" % (len(lines), LOG_NAME), end="\r\n")
> ```

### 3. Сохранить лог проверки

Закройте терминальную программу. Порт занимает кто-то один, и пока он открыт в терминале, скрипт до платы не достучится. Запустите скрипт из папки проекта:

``` bash
python check-1-3-2.py
```

>[!success] Должно получиться так
>Скрипт молчит десять секунд и печатает итог:
>
> ```
> Плата на порту /dev/tty.usbmodem1101, слушаю 10 секунд
> Принято строк: 10, лог записан в device-1-3-2.log
> ```
>
>А рядом с `main.c` появился файл `device-1-3-2.log`:
>
> ```
> задание: 1.3.2
> проект: 131-hello-usb
> устройство: 2e8a:000a
> серийный номер: E6614C775B123456
> порт: /dev/tty.usbmodem1101
> начало: 2026-09-14T18:20:11
>    0.000 <-- Hello, world!
>    1.001 <-- Hello, world!
>    2.002 <-- Hello, world!
> итог: принято строк 10 за 10.0 с
> ```

Стрелка `<--` в логе означает «принято от платы»; в следующих заданиях появится `-->` — «отправлено плате».

>[!bug] «Плата не найдена»
>Скрипт видит плату, только когда на ней работает прошивка с включённым USB-выводом. Если плата осталась в режиме загрузчика после записи `.uf2` — отключите и подключите кабель. Если порт занят терминальной программой — закройте её.

### 4. Подключить проверку задания

Создайте файл-вызов так же, как файлы в [[п1.1.5 Настройка автоматической проверки#1. Создать файлы проверок\|п1.1.5, шаг 1]]:

- имя файла — `.github/workflows/check-1-3-2.yml`;
- `name` — `1.3.2 Скрипт проверки на устройстве`;
- номер проверки в строке `uses` — `check-1-3-2.yml`.

### 5. Отправить работу

Сделайте комит со скриптом, логом и файлом-вызовом проверки и отправьте на сервер GitHub.

``` bash
git add --all
git commit -m "Сделана п1.3.2"
git push
```

>[!success] Должно получиться так
>В списке прогонов появился `1.3.2 Скрипт проверки на устройстве` с зелёной галочкой: скрипт ищет плату по коду устройства, лог снят с Raspberry Pi Pico, строк в нём десять и приходили они раз в секунду.
