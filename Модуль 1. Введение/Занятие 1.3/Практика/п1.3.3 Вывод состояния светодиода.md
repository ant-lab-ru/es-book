### Как проверить

1. **Терминал повторяет то, что видно глазами.** Нажимаете кнопку — светодиод меняет состояние, и в тот же момент в терминале появляется строка. Не нажимаете — в терминале ничего не происходит.
2. **Лог остался на диске.** В `device-1-3-3.log` строки `led on` и `led off` чередуются, а метки времени совпадают с моментами, когда вы нажимали.
3. **Автоматическая проверка курса принимает задание.** Она читает `main.c`: канал включён, подавление дребезга на месте, печать стоит внутри условия переключения. По логу она сверяет чередование состояний и убеждается, что строки шли по событию, а не потоком.

## Ход работы

>[!info] Почему выводить состояние стоит при изменении
>Напрашивается печатать состояние в каждом проходе суперцикла — так проще. Но виток здесь занимает миллисекунды, и терминал зальёт сотней одинаковых строк в секунду; найти в этом потоке момент нажатия невозможно. Сообщение имеет смысл тогда, когда что-то произошло. Это общее правило вывода в приборах, и держаться его стоит с первой программы.

### 1. Создать проект по образцу

Создайте папку `133-led-button-usb` и скопируйте в неё четыре файла проекта `123-led-button-debounce` — папку `build` не копируйте.

``` bash
cd ~/Repositories/pico/es-student

cp 123-led-button-debounce/pico_sdk_import.cmake 133-led-button-usb
cd 133-led-button-usb
```

Впишите новое имя в `project()` и добавьте в `CMakeLists.txt` две строки вывода через USB — как в [[п1.3.1 Hello World USB COM#2. Включить вывод через USB в описании сборки\|п1.3.1, шаг 2]].

Схему на макетной плате не трогайте — кнопка остаётся на том же выводе.

### 2. Собрать переключение и вывод в одном месте

Светодиод меняется в двух случаях сразу: сейчас — по кнопке, в следующем задании добавятся команды из порта. Чтобы сообщение не пришлось потом дописывать в каждом из них, соберите оба действия в одну функцию:

``` c
void set_led(bool on)
{
    gpio_put(LED_PIN, on);
    printf("led %s\n", on ? "on" : "off");
}
```

Она делает ровно две вещи: выставляет уровень на выводе и сообщает об этом наружу. Теперь новое состояние светодиода и строка в порту не могут разойтись: одно без другого не происходит.

Запись `on ? "on" : "off"` — тернарный оператор языка C: если `on` истинно, выражение даёт `"on"`, иначе `"off"`. Это обычный `if`, только записанный внутри выражения.

Сообщение пишется латиницей. Русские буквы кодируются по-разному в разных кодировках, и терминал, настроенный иначе, покажет вместо текста посторонние знаки; служебные сообщения прошивки принято писать латиницей, об этом шла речь в [[т1.3.5 Канал связи с компьютером#^intro|теории занятия]].

В суперцикле замените прямую запись в вывод светодиода вызовом этой функции — там, где программа решила, что состояние меняется. Код, который нужно дополнить, вы написали в [[п1.2.3 Программное избавление от дребезга#3. Вынести чтение в отдельную функцию\|п1.2.3, шаг 3]].

>[!success] Должно получиться так
> ```c
> // добавляем заголовочный файл стандартного ввода-вывода
> // добавляем заголовочные файлы SDK
>
> // объявляем константы
>
> bool get_button_debounce(uint pin)
> {
>     // читаем вывод устойчиво к дребезгу
> }
>
> void set_led(bool on)
> {
>     gpio_put(LED_PIN, on);
>     printf("led %s\n", on ? "on" : "off");
> }
>
> int main()
> {
>     // включаем стандартный ввод-вывод
>
>     // инициализируем и настраиваем пины светодиода и кнопки
>     // подтягиваем кнопку к питанию
>
>     // объявляем переменные
>
>     while (1)
>     {
>         // читаем состояние пина кнопки с задержкой
>
>         // если состояние сменилось — переключаем светодиод вызовом set_led
>
>         // запоминаем текущее состояние пина кнопки, как предыдущее

### 4. Создать скрипт проверки

Создайте в папке `133-led-button-usb` файл `check-1-3-3.py` — рядом с `main.c`. Наберите в нём программу целиком.

Скрипт этого задания отличается от прошлого одним: он не слушает фиксированное время, а ждёт, пока наберётся шесть строк, — и печатает их по мере поступления, чтобы вы видели, что нажатия доходят.

>[!success] Должно получиться так
> ```python
> # Проверка задания п1.3.3 на устройстве: слушает COM-порт платы, пока вы
> # нажимаете кнопку, и записывает принятое в файл device-1-3-3.log.
>
> import time
> from datetime import datetime
>
> import serial
> from serial.tools import list_ports
>
> VENDOR_ID = 0x2E8A
> PRODUCT_ID = 0x000A
>
> TASK = "1.3.3"
> PROJECT = "133-led-button-usb"
> LOG_NAME = "device-1-3-3.log"
> DURATION_S = 30
> EXPECTED_LINES = 6
>
>
> def find_board():
>     for port in list_ports.comports():
>         if port.vid == VENDOR_ID and port.pid == PRODUCT_ID:
>             return port
>     return None
>
>
> def listen(board):
>     lines = []
>     with serial.Serial(board.device, timeout=1) as port:
>         time.sleep(0.2)
>         port.reset_input_buffer()
>         started = time.monotonic()
>         while time.monotonic() - started < DURATION_S and len(lines) < EXPECTED_LINES:
>             line = port.readline().decode("ascii", "replace").strip()
>             if line:
>                 moment = time.monotonic() - started
>                 lines.append((moment, line))
>                 print("%8.3f %s" % (moment, line), end="\r\n")
>     return lines
>
>
> def write_log(board, lines):
>     with open(LOG_NAME, "w", encoding="utf-8") as log:
>         log.write("задание: " + TASK + "\n")
>         log.write("проект: " + PROJECT + "\n")
>         log.write("устройство: %04x:%04x\n" % (board.vid, board.pid))
>         log.write("серийный номер: " + str(board.serial_number) + "\n")
>         log.write("порт: " + board.device + "\n")
>         log.write("начало: " + datetime.now().isoformat(timespec="seconds") + "\n")
>         for moment, line in lines:
>             log.write("%8.3f <-- %s\n" % (moment, line))
>         log.write("итог: принято строк %d\n" % len(lines))
>
>
> board = find_board()
>
> if board is None:
>     print("Плата не найдена. Проверьте кабель и запишите на плату прошивку задания.", end="\r\n")
> else:
>     print("Плата на порту " + board.device, end="\r\n")
>     print("Нажмите кнопку %d раз — у вас %d секунд" % (EXPECTED_LINES, DURATION_S), end="\r\n")
>     lines = listen(board)
>     write_log(board, lines)
>     print("Принято строк: %d, лог записан в %s" % (len(lines), LOG_NAME), end="\r\n")
> ```
