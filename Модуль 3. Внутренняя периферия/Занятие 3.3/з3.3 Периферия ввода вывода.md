**Цель** — показать, как прибор обменивается данными с другим устройством. Связь раскладывается на договорённости, физику линии берут на себя драйверы выводов, а остальные договорённости выполняет модуль коммуникации. Модуль UART разобран по datasheet до регистров, а SPI, I²C и USB сведены с ним в одну карту интерфейсов.

Практика занятия — стенд `331-uart`, копия шаблона из занятия 2.3. Плата одна, компьютер по USB подаёт команды и читает ответы. Модуль UART сначала замыкается сам на себя, а затем два модуля одной платы, UART0 и UART1, обмениваются данными по двум проводам. Прошивка нигде не ждёт линию, обмен ведёт задача.

>[!info] Как распределена работа
>Лекция идёт по всем пяти разделам. Раздел т3.3.2 нужен к п3.3.1, т3.3.4 — к п3.3.2, т3.3.3 — к п3.3.3 и п3.3.4. Раздел т3.3.5 в практику не входит, протокольные подробности SPI и I²C разбираются в модуле 4.

>[!info] Что нужно для практики
>Для п3.3.1 нужны резистор 1 кОм и электролитический конденсатор 4,7 мкФ из комплекта. Для п3.3.2 нужна одна перемычка между GP0 и GP1, для п3.3.3 и п3.3.4 — два провода «папа — папа» вместо неё. Адаптер USB — UART и вторая плата не нужны. Для п3.3.5 к ним добавляется третий провод, GP0 — GP26, а конденсатор RC-цепи с GP26 снимается.
