>[!NOTE] Определение
>**CSV** (*англ. comma-separated values*, «значения, разделённые запятыми») — текстовый формат таблицы, в котором каждая строка файла хранит одну запись, а значения в ней разделены запятыми. Первой строкой обычно идут имена столбцов.
^def

## Что нужно знать

Файл CSV — обычный текст. Его можно прочитать глазами в любом редакторе и разобрать скриптом. В Python для этого есть встроенный модуль `csv`.

```
time_s,voltage_v,temp_c
0.000000,0.512,24.8
0.100005,0.544,24.8
```

Формат описан в RFC 4180, но многие программы его понимают по-своему. Excel с русскими настройками ждёт в CSV разделитель «точка с запятой», потому что запятая у него отделяет дробную часть числа. Файл с запятыми он откроет одним столбцом. Чтобы таблица разошлась по столбцам, файл загружают через «Данные → Из текстового/CSV-файла» и указывают разделителем запятую.
