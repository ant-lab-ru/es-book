>[!NOTE] Определение
>**Тип доступа** (*англ. access type*) — свойство битового поля, которое говорит, что делает с полем запись и что показывает чтение. В документации тип обозначают буквами:
>- **RW** (*read/write*) — поле хранит записанное значение и возвращает его при чтении
>- **RO** (*read only*) — поле показывает состояние модуля, запись его не меняет
>- **SC** (*self-clearing*) — запись единицы выполняет команду, после чего поле само возвращается в ноль
>- **WC** (*write to clear*) — поле сбрасывается записью единицы
^def
