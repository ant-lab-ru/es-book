>[!NOTE] Навык
>**Ранний выход** (*англ. early exit, guard clause*) — стиль кода, который в начале функции или итерации цикла проверяет случай, в котором нечего делать. Если действия не требуются, сразу передаёт управление — `return` в функции, `continue` в цикле. Позволяет избавить код от лишней вложенности «ёлочкой».
^def

## Что нужно знать

Условие можно записать двумя способами: завернуть полезную работу внутрь `if` или отсечь ненужный случай и выйти. Поведение одинаковое, читаются они по-разному.

При вложении читатель до самого конца блока держит в голове, внутри он или снаружи, а каждое новое условие добавляет уровень отступа. При раннем выходе условие исчерпывается в трёх строках и больше не висит над кодом: ниже идёт работа с заведомо годными данными, на том же уровне, что и всё остальное.

Отсекаемый случай называется прямо — `if (command == PICO_ERROR_TIMEOUT)` вместо `!=`, и читателю не нужно мысленно отрицать условие.

## В суперцикле

`continue` заканчивает проход и начинает следующий:

``` c
        int command = getchar_timeout_us(0);

        if (command == PICO_ERROR_TIMEOUT)
        {
            continue;
        }

        handle_command(command);
```

>[!warning] `continue` пропускает весь остаток прохода
>Дело, дописанное ниже такого выхода, будет молча пропускаться в каждом проходе, где сработало условие. Отсечение по пустому вводу поэтому ставят последним делом цикла: символа нет почти всегда, и всё, что окажется за ним, работать перестанет.

## В функции

`return` возвращает управление вызывающему:

``` c
char* stdio_task_handle()
{
    int symbol = getchar_timeout_us(0);
    if (symbol == PICO_ERROR_TIMEOUT)
    {
        return NULL;
    }

    // разбираем символ
}
```

Здесь у приёма есть второе следствие: проверка остаётся при том коде, которого касается. Функция, читающая порт, знает про `PICO_ERROR_TIMEOUT`; функция, разбирающая команды, — только свой алфавит команд. Разделение обязанностей держится само собой.
