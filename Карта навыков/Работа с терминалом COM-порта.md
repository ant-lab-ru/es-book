>[!NOTE] Навык
>**Работа с терминалом COM-порта** — умение найти COM-порт устройства в ОС, подключиться к нему терминальной программой, вводить символы и переподключаться после перезагрузки устройства.
^def

## Что нужно знать

Терминальная программа не общается с платой сама: она открывает [[COM-порт#^def|COM-порт]], который система завела при подключении устройства, и показывает приходящий в него текст. Пока плата не подключена и прошивка не запущена, порта в системе нет — открывать нечего.

Программа для этого нужна разная. На Windows штатной нет, её ставят отдельно — в курсе это [[PuTTY#^def|PuTTY]]. На macOS и Linux терминал COM-порта вызывается командой `screen`, ставить ничего не нужно.

| Система | Программа                         | Имя порта               |
| ------- | --------------------------------- | ----------------------- |
| Windows | [[PuTTY#^def\|PuTTY]]             | `COM7`                  |
| macOS   | `screen`                          | `/dev/tty.usbmodem1101` |
| Linux   | `screen`                          | `/dev/ttyACM0`          |

## Найти имя порта

Номер и имя порта система назначает сама, заранее они неизвестны и от платы к плате меняются.

### Windows

- Нажмите `Win + X` и выберите «Диспетчер устройств».
- Разверните список **Порты (COM и LPT)**.

![[Порты в диспетчере устройств.png|500]]

- Устройство будет отображаться как «Название устройства (COM#)», например, `Устройство с последовательным интерфейсом USB (COM13)`.

### macOS

1. введите в терминале:

``` bash
ls /dev
```

2. в выводе найдите устройство, содержащее `tty.usbmodem`. Скопируйте его имя.

![[Список устройств в dev на macOS.png|500]]

### Linux

Плата появляется как `/dev/ttyACM0` — если устройств несколько, номер будет другим:

``` bash
ls /dev/ttyACM*
```

Надёжный способ — посмотреть список до и после подключения платы: новая строка и есть ваш порт.

## Открыть порт

### Windows

Порт открывается из окна настройки PuTTY: тип соединения `Serial`, имя порта в поле `Serial line`, затем `Open`. Подробно, со скриншотами — в карточке [[PuTTY#Подключение к COM-порту|PuTTY]].

### macOS

``` bash
screen /dev/tty.usbmodem1101
```

### Linux

``` bash
screen /dev/ttyACM0
```

Если команда не найдена, поставьте пакет: `sudo apt install screen`. Ошибка доступа к `/dev/ttyACM0` означает, что пользователь не состоит в группе `dialout` — добавьте себя в неё командой `sudo usermod -aG dialout $USER` и перезайдите в систему.

## Отключиться от порта

В PuTTY достаточно закрыть окно терминала.

У `screen` окно то же самое, что и у командной строки, и обычные способы выхода не работают. Нажмите `Ctrl + A`, отпустите, затем `K` и подтвердите `y`.

>[!warning] Порт занят
>Пока терминал держит порт открытым, к нему не подключится никто другой — ни второй терминал, ни скрипт на Python. Перед запуском скрипта закройте терминал.

Отключение платы от USB обрывает соединение: порт исчезает из системы, а `screen` завершается сам. После перезагрузки устройства подключитесь заново — имя порта при этом может смениться.
