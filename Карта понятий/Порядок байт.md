>[!NOTE] Определение
>**Порядок байт** (*англ. byte order, endianness*) — правило, по которому байты многобайтного числа размещаются в памяти по возрастающим адресам: при прямом порядке (*англ. little-endian*) младший байт лежит по младшему адресу, при обратном (*англ. big-endian*) — старший.
^def
