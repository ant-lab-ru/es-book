>[!note] Описание
>**GCC** (*GNU Compiler Collection*) — свободный набор компиляторов, включающий компилятор языка **C**. Arm GNU Toolchain — сборка GCC для кросс-компиляции под ядра ARM: помимо компилятора в неё входят компоновщик, ассемблер и служебные программы (`objcopy`, `size` и другие). Программы набора имеют префикс `arm-none-eabi-` (архитектура ARM, без операционной системы, двоичный интерфейс EABI).
^def

## Роль в курсе

Кросс-компилятор курса: переводит программы на **C** в машинные команды ядра ARM Cortex-M0+ микроконтроллера RP2040. Вызывается не вручную, а системой сборки CMake.

## Установка

Подойдёт любая версия — курс от неё не зависит. В инструкциях ниже зафиксирована `15.3.rel1`: по ней даны точное имя файла и прямая ссылка, чтобы не искать вручную. Проверка — `arm-none-eabi-gcc --version`.

### Windows

Наборы инструментов компания Arm выкладывает на своём сервере GitLab: https://gitlab.arm.com/tooling/gnu-toolchains-for-arm. Кнопки «скачать» там нет — ссылки на файлы лежат в описаниях релизов: сначала таблица со всеми выпусками, в ней ссылка на нужный, а уже внутри — файлы для всех систем.

Нужен установщик с целевой платформой `arm-none-eabi` для 64-разрядной Windows:

`arm-gnu-toolchain-15.3.rel1-mingw-w64-x86_64-arm-none-eabi.msi`

Прямая ссылка на него: https://gitlab.arm.com/api/v4/projects/tooling%2Fgnu-toolchains-for-arm/packages/generic/gnu-toolchain/15.3.rel1/arm-gnu-toolchain-15.3.rel1-mingw-w64-x86_64-arm-none-eabi.msi

1. Запустите установщик и пройдите шаги мастера. Настроек менять не нужно, потребуется только принять лицензионное соглашение — отметить `I accept the terms in the License Agreement`. Обратите внимание на папку установки, она понадобится дальше: по умолчанию это `C:\Program Files\Arm\GNU Toolchain mingw-w64-x86_64-arm-none-eabi`, набор занимает около гигабайта.

![[Папка установки Arm GNU Toolchain.png|500]]

2. Добавьте в `PATH` папку `bin` внутри папки установки — как это сделать, описано в навыке [[Настройка переменных среды#^def|Настройка переменных среды]]:

```
C:\Program Files\Arm\GNU Toolchain mingw-w64-x86_64-arm-none-eabi\bin
```

Про переменные среды установщик не спрашивает: сразу после установки команда `arm-none-eabi-gcc` не находится, путь прописывается вручную.

3. Перезапустите терминал и проверьте, что компилятор отвечает:

``` powershell
arm-none-eabi-gcc --version
```

В ответе — версия набора и версия GCC:

```
arm-none-eabi-gcc.exe (Arm GNU Toolchain 15.3.Rel1 (Build arm-15.149)) 15.3.1 20260627
```

>[!bug] Windows не пропускает скачанный файл
>Перед запуском установщика система может показать предупреждение SmartScreen с именем издателя `ARM LIMITED`. Так помечается любой файл, полученный из интернета, — разрешите запуск.

### macOS

Три способа, рекомендуем первый. Если не сработает, то второй. Если второй не сработает, то третий.

1. Готовая сборка Arm через [[Homebrew#^def|Homebrew]] — тот же набор, что и установщик для Windows, версия `15.3.rel1`:

``` bash
brew install --cask gcc-arm-embedded
```

2. Формула Homebrew — собственная сборка проекта, версия свежее (`16.2.0`), состав набора тот же:

``` bash
brew install arm-none-eabi-gcc
```

3. Вручную с GitLab компании Arm — тот же пакет, который ставит первый способ. Подходит, когда [[Homebrew#^def|Homebrew]] нет и ставить его не хочется. Узнайте архитектуру своего компьютера (меню Apple → «Об этом Mac» → строка «Чип») и скачайте файл:

| Архитектура                | Файл                                                          |
| -------------------------- | ------------------------------------------------------------- |
| Apple Silicon (M1 и новее) | `arm-gnu-toolchain-15.3.rel1-darwin-arm64-arm-none-eabi.pkg`  |
| Intel                      | `arm-gnu-toolchain-14.2.rel1-darwin-x86_64-arm-none-eabi.pkg` |

Для Intel последняя доступная версия — `14.2.rel1`: сборок под неё Arm больше не выпускает. Для курса этого достаточно.

>[!warning] Пакет не добавляет себя в PATH
>После установки компилятор лежит в `/Applications/ArmGNUToolchain/15.3.rel1/arm-none-eabi/bin/`, но команда `arm-none-eabi-gcc` не найдётся: путь к нему нужно задать самому — см. [[Настройка переменных среды#^def|Настройка переменных среды]]. Первый способ этот шаг делает за вас, третий — нет.
>
> ``` bash
> echo 'export PATH="/Applications/ArmGNUToolchain/15.3.rel1/arm-none-eabi/bin:$PATH"' >> ~/.zshrc
> ```
>
>Перезапустите терминал и проверьте командой из начала карточки. В пути стоит номер версии — при переходе на следующую строку её придётся поправить.

>[!bug] macOS не пропускает скачанный файл
>Система может отказаться открывать пакет, полученный из интернета. Щёлкните по нему правой кнопкой и выберите «Открыть» — появится то же окно, но с кнопкой подтверждения. Это тот же механизм, что SmartScreen в Windows.

``` bash
sudo apt update
sudo apt install gcc-arm-none-eabi libnewlib-arm-none-eabi build-essential
```
