**Результат** — прибор `311-adc` знает температуру своего кристалла. Команда `get_temp` отвечает градусами Цельсия, которые `platform` получает от встроенного датчика по формуле из RP2040 Datasheet.
^intro

## Задание

### Что должно получиться

- [ ] `platform` включает датчик температуры и переводит напряжение на нём в градусы
- [ ] Команда `get_temp` отвечает строкой вида `temp: 27.4 C`
- [ ] Температура похожа на комнатную, но на несколько градусов выше
- [ ] После `get_temp` команда `get_voltage` по-прежнему меряет напряжение на GP26
- [ ] Лог `device-3-1-2.log` снят, коммит отправлен, проверка `3.1.2` зелёная

### Как проверить

1. **Температура похожа на правду.** Спросите `get_temp` несколько раз. Значения близки друг к другу и лежат около комнатной температуры. Прижмите палец к корпусу RP2040 на полминуты и спросите снова. Температура должна немного вырасти.
2. **Лог прогона лежит в проекте.** Скрипт задания записывает обмен в `device-3-1-2.log`.
3. **Автоматическая проверка курса принимает задание.** Она ищет в `platform.c` включение датчика, выбор канала 4 и формулу с числами 0,706 и 0,001721. В логике формулы быть не должно. В логе она ищет три ответа `get_temp` от 10 до 50 °C, расходящиеся не больше чем на 3 °C, и ответ `get_voltage` после них.

## Ход работы

### 1. Найти формулу датчика

Откройте [[RP2040 Datasheet.pdf#page=564|RP2040 Datasheet, раздел «4.9.5. Temperature Sensor»]]. Датчик подключён к пятому входу АЦП, каналу 4. При 27 °C напряжение на нём около 0,706 В и падает на 1,721 мВ на каждый градус. Отсюда формула перевода:

```
T = 27 − (U − 0,706) / 0,001721
```

Здесь `U` — напряжение на датчике в вольтах. Там же сказано, что питание датчика включают отдельно, битом `TS_EN`.

### 2. Добавить датчик в platform

Формула датчика — знание о железе, и её место в `platform` (правило П13 [[ТЗ 2.3 Шаблон проектирования#4. Правила|ТЗ 2.3]]). В SDK питание датчика включает `adc_set_temp_sensor_enabled()`. Вызовите её в `platform_init()` после запуска АЦП.

>[!success] Должно получиться так
> ```c
> // встроенный датчик температуры — канал 4
> #define ADC_TEMP_CHANNEL 4
>
> // в platform_init(): включить питание датчика
> adc_set_temp_sensor_enabled(true);
>
> // температура кристалла по встроенному датчику, градусы Цельсия
> float platform_temp_read(void)
> // выбрать канал датчика
> // снять отсчёт и перевести код в вольты, как в platform_voltage_read()
> // перевести вольты в градусы по формуле шага 1
> ```

| Что нужно написать | Где это разбиралось |
| --- | --- |
| выбор канала, отсчёт, перевод кода в вольты | [[п3.1.1 Измерение напряжения#3. Подключить АЦП в platform\|п3.1.1, шаг 3]] |
| объявление функции в `platform.h` | [[п3.1.1 Измерение напряжения#3. Подключить АЦП в platform\|п3.1.1, шаг 3]] |
| формула с числами `float` | [[п2.2.3 Цена вычислений#3. Замерить расчёт\|п2.2.3, шаг 3]] |

Каждая функция выбирает свой канал перед отсчётом. Тогда `get_voltage` и `get_temp` можно вызывать в любом порядке.

### 3. Добавить команду get_temp

Обработчик спрашивает температуру у `platform` и печатает её с одним знаком после точки, как `get_voltage` в [[п3.1.1 Измерение напряжения#4. Добавить команду get_voltage|п3.1.1, шаг 4]].

>[!success] Должно получиться так
> ```c
> // температура у platform, ответ temp: <температура> C
> static void cmd_get_temp(const command_t *command)
>
> // в таблице команд
> { "get_temp", "chip temperature, degrees Celsius", cmd_get_temp },
> ```

### 4. Проверить на плате

Соберите проект, запишите прошивку и спросите температуру в терминале:

>[!success] Должно получиться так
> ```
> get_temp
> temp: 24.8 C
> get_temp
> temp: 24.3 C
> ```

Температура кристалла обычно на несколько градусов выше комнатной. Кристалл нагревается от собственной работы. К тому же датчик очень чувствителен к опорному напряжению. Ошибка опоры в 1% сдвигает результат больше чем на 4 °C, об этом в [[т3.1.3 АЦП RP2040#Датчик температуры|т3.1.3]]. Поэтому точную температуру воздуха так не измеряют, а следить, не перегрелся ли кристалл, удобно.

### 5. Снять лог

Скопируйте [[check-3-1-2.py]] в папку проекта и запустите:

``` bash
python check-3-1-2.py
```

Скрипт спрашивает паспорт, трижды температуру и один раз напряжение.

>[!success] Должно получиться так
> ```
> get_temp
> temp: 24.8 C
> get_temp
> temp: 24.3 C
> get_temp
> temp: 24.8 C
> get_voltage
> voltage: 0.595 V
> Обмен записан в device-3-1-2.log
> ```
