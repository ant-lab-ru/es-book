>[!NOTE] Определение
>**PROJECT_NAME** (*англ. project name*) — переменная CMake, в которую попадает имя, объявленное командой `project()`. Запись `${PROJECT_NAME}` подставляет имя проекта в любом месте описания сборки, это позволяет задавать имя в файле ровно один раз.
^def

## Что нужно знать

Нередко проекты ВПО заводятся копированием предыдущего.

В `CMakeLists.txt` имя цели встречается несколько раз. В командах:
- `project()`
- `add_executable()`
- `target_link_libraries()`
- `pico_set_linker_script()`
- `pico_add_extra_outputs()`

Если имя вписано текстом, при копировании папки проекта в `CMakeLists.txt` его нужно поменять во всех командах. Пропущенная замена часто является причиной неуспешной сборки и отнимает время на поиск и решение проблемы. При использовании `${PROJECT_NAME}` после копирования правится одна строка с командой `project()`. Остальные включения названия проекта подставляют новое имя сами.
