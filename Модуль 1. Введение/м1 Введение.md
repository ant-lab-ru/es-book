## 1. Аннотация

Модуль открывает курс и создаёт понятийный мост между знакомыми студентам персональными компьютерами и микроконтроллерами. Студенты с первого занятия получают работающий результат — мигающий светодиод — и затем последовательно разбирают, что именно произошло: как устроен микроконтроллер, что такое встроенное программное обеспечение, как оно собирается и записывается в память. Модуль закладывает базовый рабочий процесс: написать код → собрать → прошить → закоммитить, который будет использоваться на протяжении всего курса.

## 2. Результаты обучения

По завершении модуля студент будет:

### Знать
- Что такое процессор, микропроцессор, интегральная схема, микроконтроллер — и в чём между ними разница
- Что такое встроенное программное обеспечение (ВПО) и его три формы: исходный код, файл-образ, записанная прошивка
- Из каких компонентов состоит RP2040: ядра Cortex-M0+, шина, SRAM, ROM, XIP, периферия
- Какие программы входят в toolchain и за что каждая из них отвечает
- Что такое SDK и что входит в Pico SDK

### Понимать
- Чем микроконтроллер отличается от Raspberry Pi 4 и когда нужно использовать каждый из них
- Как исходный код на C превращается в файл прошивки: компиляция → компоновка → конвертация
- Что такое кросс-компиляция и зачем она нужна

### Уметь применять
- Установить toolchain: git, cmake, make, arm-none-eabi-gcc, picotool, VSCode
- Клонировать pico-sdk и настроить переменную окружения `PICO_SDK_PATH`
- Создать проект с нуля: написать `main.c`, `CMakeLists.txt`, подключить `pico_sdk_import.cmake` и linker script
- Собрать прошивку командами `cmake` + `make` и получить `.uf2` файл
- Записать прошивку в Raspberry Pi Pico через режим USB-накопителя (BOOTSEL)
- Создать репозиторий, настроить `.gitignore` и закоммитить исходники прошивки

### Уметь анализировать и решать задачи

- Найти нужную характеристику в datasheet RP2040 или Pico (через Ctrl+F по ключевому слову)
- Воспроизвести сборку прошивки с нуля: склонировать чужой репозиторий → собрать → прошить
- Прочитать ошибку сборки cmake/make и определить, какого файла или переменной не хватает

## 6. Оборудование и материалы

### Оборудование

- Raspberry Pi Pico × 1 на каждого студента
- USB-кабель (Micro-USB) × 1 на студента
- ПК (Windows / macOS / Linux) с доступом в интернет

### Программное обеспечение

- git
- cmake ≥ 3.15
- make (MinGW на Windows)
- arm-none-eabi-gcc (GNU Arm Embedded Toolchain)
- picotool
- VS Code
- pico-sdk (клонируется на занятии)
- PuTTY
