>[!note] Описание
>**PuTTY** — программа-терминал: открывает COM-порт и показывает поток байтов, который шлёт устройство, а набранное с клавиатуры отправляет обратно.
^def

## Роль в курсе

Через PuTTY читается вывод прошивки по USB и отправляются ей команды — начиная с занятия [[з1.3 Встроенное программное обеспечение#^intro|1.3]].

PuTTY нужна на Windows: штатной терминальной программы для COM-порта в системе нет. На macOS и Linux устанавливать её не нужно — там терминал COM-порта уже встроен, см. [[Работа с терминалом COM-порта#^def|Работа с терминалом COM-порта]].

## Установка

### Windows

1. Скачать бинарный файл консольной программы PuTTY со [страницы загрузки](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html) — раздел `Alternative binary files`, файл `putty.exe` для 64-bit x86:

![[Страница загрузки PuTTY.png|500]]

2. Запустить скачанный файл. Установщик не нужен: `putty.exe` запускается сам по себе, двойным щелчком. Основное окно программы PuTTY выглядит следующим образом:

![[Окно настройки PuTTY.png|400]]

## Подключение к COM-порту

PuTTY работает через окно настройки: порт выбирается в нём, а не аргументом командной строки.

1. Записать в плату прошивку с USB CDC и определить имя COM-порта — [[Работа с терминалом COM-порта#Найти имя порта|как его найти]].
2. В `Connection type` выбрать `Serial`. В `Serial line` указать название COM-порта:

![[Подключение к COM-порту в PuTTY.png|400]]

>[!ATTENTION] Внимание!
>В данном случае мы подключаемся не напрямую к UART, а к виртуальному COM-порту, который создает микроконтроллер RP2040 на PICO. USB данные не с фиксированной скоростью (baudrate), а пакетами по высокоскоростному USB-протоколу. **Поэтому в этом менять значение скорости не обязательно.**

3. Нажать `Open` — откроется окно терминала, в котором виден приходящий от платы текст.

Чтобы закрыть соединение, закройте окно терминала.
