>[!note] Описание
>**pico-sdk** — официальный набор инструментов разработки для микроконтроллеров RP2040 и RP2350 на языке **C**: библиотеки для работы с периферией, стартап-код, скрипты компоновщика и интеграция с CMake. Исходный код открыт под лицензией BSD-3-Clause.
^def

## Роль в курсе

Основа всех проектов для целевого устройства: программы курса используют функции pico-sdk для доступа к периферии микроконтроллера.

## Установка

SDK не устанавливается, а клонируется как репозиторий Git — курс работает на версии `2.3.0`:

``` bash
git clone -b 2.3.0 https://github.com/raspberrypi/pico-sdk.git
cd pico-sdk
git submodule update --init
```

Подмодули обязательны: поддержка USB (TinyUSB) и другие компоненты подключены к SDK именно так, без них проект не соберётся.

Путь к папке SDK проекты получают через переменную среды `PICO_SDK_PATH` — её нужно создать один раз ([[Настройка переменных среды#^def|Настройка переменных среды]]).

>[!warning] Версия SDK и версия picotool должны совпадать
>Курс закреплён на `2.3.0` в обеих программах. Ключ `-b 2.3.0` берёт помеченную версию, а не текущее состояние ветки `master`: так у всех обучающихся окружение одинаковое, а инструкции курса не расходятся с реальностью при выходе новых версий.
