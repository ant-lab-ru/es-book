# «Встраиваемые системы» от команды [ant-lab](https://ant-lab.ru/)

Книга о разработке устройств на микроконтроллерах в формате Obsidian: карта понятий, карта навыков, карта инструментов, теория и практика.

### Инструкция

1. Установить [Obsidian](https://obsidian.md/)
2. Клонировать этот репозиторий
3. В Obsidian:
    - Открыть папку с локальной копией как хранилище
    - Разрешить плагины, когда Obsidian спросит — без них не отрисуются схемы
    - Открыть заметку **Встраиваемые системы**
4. Проходить **занятия**:
    - читать теорию по порядку
    - выполнять практику — задание и ход работы
    - разбирать схемы и изображения
5. Получать свежую версию книги: `git pull`
