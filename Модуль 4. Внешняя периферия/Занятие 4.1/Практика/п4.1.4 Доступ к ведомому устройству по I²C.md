## Ход работы

### 1. Соединить I²C0 и I²C1

![[I²C — соединения контроллеров Pico.excalidraw|100%]]

При снятом питании добавьте две перемычки. BME280 оставьте подключённым.

| Линия | Ведущий I²C0 | Ведомый I²C1 |
| --- | --- | --- |
| SDA | GP8, контакт 11 | GP6, контакт 9 |
| SCL | GP9, контакт 12 | GP7, контакт 10 |

>[!info] Одна пара подтяжек на общую шину
>У GYBMEP подтяжки на модуле действуют и для новой ветви. Дополнительная пара не нужна. Если отключите модуль, проверьте, что SDA и SCL всё ещё имеют подтяжку к 3,3 В.

### 2. Подключить готовый обработчик I²C

Добавьте `pico_i2c_slave` к зависимостям `platform` в CMake. В `platform.c` подключите `pico/i2c_slave.h`. В `platform.h` замените объявление `platform_slave_init()` следующим блоком и удалите `platform_time_ms()`. Типы описывают указатели на две функции доступа к регистрам. Эти функции будут переданы из `slave.c`.

>[!info] Объявления для `platform.h`
>```c
> typedef uint8_t (*platform_register_read_t)(uint8_t reg);
> typedef void (*platform_register_write_t)(uint8_t reg, uint8_t value);
>
> void platform_slave_init(uint8_t address, platform_register_read_t read_register,
>                          platform_register_write_t write_register);
>```

В `platform.c` перед `platform_start_core1()` добавьте переменные ведомого. Затем замените прежнюю `platform_slave_init()` приведённой парой функций. Удалите реализацию `platform_time_ms()`, она требовалась для мигания.

>[!info] Состояние приёма в `platform.c`
>```c
> static platform_register_read_t i2c_read_register;
> static platform_register_write_t i2c_write_register;
> static uint8_t i2c_register;
> static enum { I2C_REGISTER, I2C_VALUE, I2C_DONE } i2c_phase;
>```

>[!info] Готовая обработка I²C в `platform.c`
>```c
> static void i2c_slave_event(i2c_inst_t *i2c, i2c_slave_event_t event)
> {
>     switch (event)
>     {
>     case I2C_SLAVE_RECEIVE:
>         while (i2c_get_read_available(i2c))
>         {
>             uint8_t byte = i2c_read_byte_raw(i2c);
>             if (i2c_phase == I2C_REGISTER)
>             {
>                 i2c_register = byte;
>                 i2c_phase = I2C_VALUE;
>             }
>             else if (i2c_phase == I2C_VALUE)
>             {
>                 i2c_write_register(i2c_register, byte);
>                 i2c_phase = I2C_DONE;
>             }
>         }
>         break;
>     case I2C_SLAVE_REQUEST:
>         i2c_write_byte_raw(i2c, i2c_read_register(i2c_register));
>         break;
>     case I2C_SLAVE_FINISH:
>         // Повторный START завершает фазу записи, сохраняя номер регистра.
>         i2c_phase = I2C_REGISTER;
>         break;
>     }
> }
>
> void platform_slave_init(uint8_t address, platform_register_read_t read_register,
>                          platform_register_write_t write_register)
> {
>     gpio_init(PICO_DEFAULT_LED_PIN);
>     gpio_put(PICO_DEFAULT_LED_PIN, 0);
>     gpio_set_dir(PICO_DEFAULT_LED_PIN, GPIO_OUT);
>
>     i2c_read_register = read_register;
>     i2c_write_register = write_register;
>     i2c_init(i2c1, BUS_BAUD);
>     gpio_disable_pulls(6);
>     gpio_set_function(6, GPIO_FUNC_I2C);   // SDA
>     gpio_disable_pulls(7);
>     gpio_set_function(7, GPIO_FUNC_I2C);   // SCL
>     i2c_slave_init(i2c1, address, i2c_slave_event);
> }
>```

Вызов `i2c_slave_init()` выполняется на ядре 1. Библиотека `pico_i2c_slave` разрешает события контроллера, регистрирует свой обработчик и включает `I2C1_IRQ` на текущем ядре. При прерывании SDK вызывает `i2c_slave_event()`. После обработки ядро возвращается к суперциклу.

| Событие | Действие |
| --- | --- |
| `I2C_SLAVE_RECEIVE` | `i2c_read_byte_raw()` забирает байт из очереди. Первый байт выбирает регистр, второй содержит значение. |
| `I2C_SLAVE_REQUEST` | `i2c_write_byte_raw()` кладёт значение регистра в очередь передачи. |
| `I2C_SLAVE_FINISH` | Сбрасывает этап приёма. Номер регистра сохраняется для чтения после повторного START. |

### 3. Подключить регистры к светодиоду

Скопируйте блок целиком взамен содержимого `logic/slave/slave.c`. Используйте `slave.h` из п4.1.3. Теперь светодиод следует за значением `STATE`.

>[!info] Готовый код `logic/slave/slave.c`
>```c
> #include "logic/slave/slave.h"
> #include "platform/platform.h"
>
> #include <stdatomic.h>
>
> // Состояние меняет обработчик I²C, а суперцикл читает его.
> static _Atomic uint8_t led_state;
>
> static uint8_t read_register(uint8_t reg)
> {
>     if (reg == SLAVE_REG_STATE)
>     {
>         return atomic_load_explicit(&led_state, memory_order_relaxed);
>     }
>
>     return 0xFF;
> }
>
> static void write_register(uint8_t reg, uint8_t value)
> {
>     if (reg == SLAVE_REG_CMD && (value == 'e' || value == 'd'))
>     {
>         atomic_store_explicit(&led_state, value == 'e', memory_order_relaxed);
>     }
>     else if (reg == SLAVE_REG_STATE && value <= 1)
>     {
>         atomic_store_explicit(&led_state, value, memory_order_relaxed);
>     }
> }
>
> void slave_device_init(void)
> {
>     platform_slave_init(SLAVE_I2C_ADDRESS, read_register, write_register);
> }
>
> void slave_device_handle(void)
> {
>     platform_led_set(atomic_load_explicit(&led_state, memory_order_relaxed) != 0);
> }
>```

>[!info] Одно состояние в суперцикле и в прерывании
>`led_state` объявлена с `_Atomic`. Функции `atomic_store_explicit()` и `atomic_load_explicit()` записывают и читают целое значение. Прерывание I²C может произойти в ходе суперцикла того же ядра. `memory_order_relaxed` достаточно, потому что вместе с состоянием светодиода мы не согласуем доступ к другим данным.

### 4. Проверить оба адреса

Соберите проект и загрузите бинарный файл на Pico. Скопируйте [[check-4-1-4.py]] в папку проекта. Закройте USB-терминал и запустите скрипт. Для BME280 на `0x77` добавьте `--address 0x77`.

```bash
python check-4-1-4.py
```

Ниже приведён конец вывода после справки.

>[!success] Должно получиться так
>```text
> <-- i2c: addr 0x76 reg 0xD0 value 0x60
> --> i2c_write_reg 0x42 0x00 0x65
> <-- i2c_write_reg 0x42 0x00 0x65
> <-- i2c: addr 0x42 reg 0x00 sent 0x65
> --> i2c_read_reg 0x42 0x01
> <-- i2c_read_reg 0x42 0x01
> <-- i2c: addr 0x42 reg 0x01 value 0x01
> ...

>```

Если хотите отдельно увидеть светодиод, снова откройте терминал. Команда `i2c_write_reg 0x42 0x00 0x65` включает его. Команда `i2c_write_reg 0x42 0x01 0x00` выключает.
