Приложение к [[ТЗ 2.3 Прибор|части 1 технического задания, «Прибор»]]. Описывает команды прибора — его API. Как команда передаётся в кадре, описано в [[ТЗ 2.3 Приложение А. Протокол]]; обозначения в форматах — те же, что в разделе 2 приложения А. Окончание строки ответа `CR LF` в форматах не показано.
^intro

## 1. Общие правила

- **Числовой аргумент** — десятичная запись из одних цифр, значение от 0 до 4 294 967 295. Запись со знаком (`-1`, `+5`), с посторонними символами (`5x`, `0x10`) или со значением больше 4 294 967 295 — ошибка в записи аргумента.
- **Ошибка в записи аргументов** — неверная запись числового аргумента или число аргументов вне допустимого. Команда на неё отвечает строкой `error: usage <синтаксис>` и ничего не меняет.
- **Команда без аргументов** игнорирует переданные аргументы.

## 2. Перечень команд

| Команда | Функция | Описание |
| --- | --- | --- |
| `help` | Ф1 | перечень команд со справкой |
| `info` | Ф2 | паспорт прибора |
| `uptime` | Ф2 | время с момента сброса |
| `led_enable` | Ф3 | перевести светодиод в состояние «горит» |
| `led_disable` | Ф3 | перевести светодиод в состояние «выключен» |
| `led_blink` | Ф3 | перевести светодиод в состояние «мигает» |
| `led_period` | Ф3 | задать период мигания |
| `button` | Ф4 | состояние кнопки и число нажатий |
| `pi_start` | Ф5 | запустить расчёт π |
| `pi` | Ф5 | результат или состояние расчёта π |
| `profiling` | Ф6 | результаты секундомеров |
| `profiling_reset` | Ф6 | сбросить результаты секундомеров |

## 3. Описание команд

### `help`

| | |
| --- | --- |
| Синтаксис | `help` |
| Описание | перечисляет все команды прибора, начиная с `help`, по строке на команду |
| Аргументы | нет |
| Ответ | `<имя> SP {SP} <справка>` — для каждой команды |
| Ошибки | нет |

```
> help
help             list of commands
info             device passport
...
```

### `info`

| | |
| --- | --- |
| Синтаксис | `info` |
| Описание | выводит паспорт прибора |
| Аргументы | нет |
| Ответ | восемь строк в порядке таблицы ниже |
| Ошибки | нет |

| Строка ответа | Значение |
| --- | --- |
| `name: <имя>` | имя прошивки из `firmware.h` |
| `version: <версия>` | версия прошивки из `firmware.h`, вида `1.0.0` |
| `project: <проект>` | имя проекта, `231-firmware-template` |
| `repo: <адрес>` | адрес репозитория студента |
| `board: <плата>` | значение `PICO_BOARD`, с которым собрана прошивка |
| `serial: <номер>` | серийный номер платы, 16 шестнадцатеричных цифр |
| `chip: manufacturer 0x<код>, part 0x<код>, revision <ревизия>` | поля регистра `CHIP_ID`: производитель — 3 шестнадцатеричные цифры, изделие — 4, ревизия — десятичное число |
| `pico-sdk: <версия>` | версия Pico SDK |

### `uptime`

| | |
| --- | --- |
| Синтаксис | `uptime` |
| Описание | выводит время с момента сброса |
| Аргументы | нет |
| Ответ | `uptime: <время> ms`, время — десятичное число миллисекунд |
| Ошибки | нет |

### `led_enable`, `led_disable`, `led_blink`

| | |
| --- | --- |
| Синтаксис | `led_enable` \| `led_disable` \| `led_blink` |
| Описание | переводят светодиод в состояние «горит», «выключен», «мигает» соответственно |
| Аргументы | нет |
| Ответ | `led: <состояние>, period <период> ms`, состояние — `off` \| `on` \| `blink`, период — десятичное число миллисекунд |
| Ошибки | нет |

```
> led_enable
led: on, period 1000 ms
```

### `led_period`

| | |
| --- | --- |
| Синтаксис | `led_period <period_ms>` |
| Описание | задаёт период мигания; состояние светодиода не меняет |
| Аргументы | `<period_ms>` — числовой аргумент, период в миллисекундах, от 1 |
| Ответ | `led: <состояние>, period <период> ms`, как у `led_enable` |
| Ошибки | `error: usage led_period <period_ms>` — нет аргумента, больше одного аргумента или ошибка в записи;<br>`error: period_ms must be greater than 0` — `<period_ms>` равен 0 |

```
> led_period 500
led: blink, period 500 ms
> led_period -1
error: usage led_period <period_ms>
```

### `button`

| | |
| --- | --- |
| Синтаксис | `button` |
| Описание | выводит состояние кнопки и число нажатий с момента сброса |
| Аргументы | нет |
| Ответ | `button: <состояние>, presses <число>`, состояние — `pressed` \| `released`, число — десятичное |
| Ошибки | нет |

### `pi_start`

| | |
| --- | --- |
| Синтаксис | `pi_start [<terms>]` |
| Описание | запускает расчёт π и отвечает сразу, не дожидаясь результата |
| Аргументы | `<terms>` — числовой аргумент, число членов ряда, от 1; по умолчанию 1 000 000 |
| Ответ | `pi: started, <terms> terms` |
| Ошибки | `error: usage pi_start [<terms>]` — больше одного аргумента или ошибка в записи;<br>`error: terms must be greater than 0` — `<terms>` равен 0;<br>`error: pi is busy` — расчёт уже идёт |

### `pi`

| | |
| --- | --- |
| Синтаксис | `pi` |
| Описание | выводит результат последнего расчёта или состояние расчёта, если результата нет |
| Аргументы | нет |
| Ответ | `pi: not started` — расчёт не запускался;<br>`pi: running` — расчёт идёт;<br>`pi: <значение> in <время> ms` — расчёт закончен; значение — с 9 знаками после точки, время — десятичное число миллисекунд |
| Ошибки | нет |

```
> pi
pi: 3.141591654 in 4712 ms
```

### `profiling`

| | |
| --- | --- |
| Синтаксис | `profiling` |
| Описание | выводит результаты всех заведённых секундомеров с момента сброса |
| Аргументы | нет |
| Ответ | по строке на секундомер:<br>`<имя> SP {SP} count <число> SP {SP} mean <среднее> us SP {SP} max <максимум> us`;<br>число — десятичное, среднее — микросекунды с двумя знаками после точки, максимум — целые микросекунды;<br>в сборке без профилирования — одна строка `profiling is disabled in this build` |
| Ошибки | нет |

Имена секундомеров: `loop` — итерация суперцикла, `command` — приём символа и выполнение команды, `led`, `button`, `pi` — обработчики задач.

```
> profiling
loop       count 812345     mean 5.12 us  max 498 us
command    count 812345     mean 1.03 us  max 310 us
...
```

### `profiling_reset`

| | |
| --- | --- |
| Синтаксис | `profiling_reset` |
| Описание | сбрасывает результаты всех секундомеров |
| Аргументы | нет |
| Ответ | `profiling reset` |
| Ошибки | нет |
